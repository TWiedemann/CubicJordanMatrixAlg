1 Introduction

This package allows symbolic computations in free multiplicative conic alternative algebras \(C\) over free commutative rings \(k\). It also supports computations in several structures that can be constructed from \(C\) and \(k\): namely, cubic Jordan matrix algebra as well as certain Lie algebras and groups which are graded by the root systems \(G_2\) and \(F_4\).

This package was originally developed for certain computations in [DW26], which contains detailed descriptions of the underlying mathematical structures. A less technical overview of the functionality of the package is available in [Wie26].

1.1 Notational conventions

Throughout this documentation, we use the following conventions:

  • Conic algebras are denoted by C and their commutative base rings by k.

  • Elements of a conic algebra are denoted by a, b, c.

  • Elements of the commutative base ring of a conic algebra are denoted by t, s, r.

  • Elements of a cubic Jordan matrix algebra are denoted by cub.

  • Elements of the Lie algebra \(L\) over a conic algebra are denoted by lie.

  • Elements of a Brown algebra (that is, of the components \(L_1\) and \(L_{-1}\) of a Lie algebra \(L\)) are denoted by brown.

  • Elements of \(L_0\), the 0-space of \(L\), are denoted by l0.

  • Elements of DD (one of the components of \(L_0\)) are denoted by ddEl.

  • Endomorphisms of \(L\) are denoted by f, g.

  • We denote by i, j, l integers in [1,2,3] and by p arbitrary integers.

1.2 Multiple conic algebras in the same GAP session

Elements of distinct conic algebras are always regarded as distinct, even if they share the same name:

gap> C := ConicAlgebra(3, 2, 2);; D := ConicAlgebra(3, 2, 2);;
gap> ConicAlgIndet(C, 1);
(1)*a1
gap> ConicAlgIndet(D, 1);
(1)*a1
gap> ConicAlgIndet(C, 1) = ConicAlgIndet(D, 1);
false

However, the elements of their base rings are (quotients of) polynomials over the integers, and will coincide if they share the same name:

gap> ConicTr(ConicAlgIndet(C, 1));
tr(a1)
gap> ConicTr(ConicAlgIndet(D, 1));
tr(a1)
gap> ConicTr(ConicAlgIndet(C, 1)) = ConicTr(ConicAlgIndet(D, 1));
true

1.3 For advanced users

While the main functions of the package are described in this documentation, more functions and their documentation can be found by studying the GAP source files in CubicJordanMatrixAlg/gap. Most files are commited to building up the desired structures step by step (similarly as this manual does), and the precise order in which they are loaded can be read off from CubicJordanMatrixAlg/init.g. The most complicated tasks are the simplification functions in simplify.g and the construction of the trace function in comring.g.
