3 Cubic Jordan matrix algebras

This section describes the functions relating to the cubic Jordan matrix algebra \(J := \text{Her}_3(C, \Gamma)\) that is defined over any conic algebra \(C\). Throughout this section, we denote the conic algebra over which we work by \(C\) and its base ring by \(k\). The addition \(J \times J \to J\) and the scalar multiplication \(k \times J \to J\) are available as + and *.

3.1 Constructing elements of cubic Jordan matrix algebras

3.1-1 CubicConicEl
‣ CubicConicEl( a, i )( operation )

Returns a[jl] where [i,j,l] is the unique cyclic permutation of [1,2,3] starting from i.

3.1-2 CubicComEl
‣ CubicComEl( t, i )( operation )

Returns the element of \(J\) which is denoted by \(te_i\) in [DMW]. It is printed as t[ii].

3.1-3 CubicEl
‣ CubicEl( z, i, j )( operation )

Returns z[ij]. Thus z must lie in \(k\) if i=j and in \(C\) otherwise.

3.1-4 CubicElFromTuple
‣ CubicElFromTuple( t, s, r, a, b, c )( operation )

Returns t[11] + s[22] + r[33] + a[23] + b[31] + c[12].

3.1-5 CubicZero
‣ CubicZero( C )( operation )

Returns the zero element of the conic algebra over C.

3.1-6 CubicConicPart and CubicComPart
‣ CubicConicPart( cub, i )( operation )
‣ CubicComPart( cub, i )( operation )

Returns the corresponding component of cub. For example, for cub = t[11] + s[22] + r[33] + a[23] + b[31] + c[12], we have CubicConicPart(cub, 1) = a and CubicComPart(cub, 2) = s.

3.2 The cubic norm structure

A cubic Jordan matrix algebra \(J\) has the structure of a cubic norm structure, whose structural maps can be computed as follows.

3.2-1 CubicNorm
‣ CubicNorm( cub )( operation )

Returns the norm of cub, which is an element of \(k\).

3.2-2 CubicAdj
‣ CubicAdj( cub )( operation )

Returns the adjoint \(\text{cub}^\sharp\) of cub, which is an element of \(J\).

3.2-3 CubicBiTr
‣ CubicBiTr( cub1, cub2 )( operation )

Returns the bilinear trace \(T(\text{cub1}, \text{cub2})\) of cub1, cub2, which is an element of \(k\).

3.2-4 CubicCross
‣ CubicCross( cub1, cub2 )( operation )

Returns \(\text{cub1} \times \text{cub2}\), which is an element of \(J\).

3.3 The Jordan algebra structure

A cubic Jordan matrix algebra \(J\) has the structure of a quadratic Jordan algebra, whose structural maps can be computed as follows.

3.3-1 JordanU
‣ JordanU( cub1, cub2 )( operation )

Returns \(U_{\text{cub1}}(\text{cub2})\), which is an element of \(J\).

3.3-2 JordanULin
‣ JordanULin( cub1, cub2, cub3 )( operation )

Returns \(U_{\text{cub1},\text{cub2}}(\text{cub3})=U_{\text{cub1}+\text{cub2}}(\text{cub3}) - U_{\text{cub1}}(\text{cub3}) - U_{\text{cub2}}(\text{cub3})\), which is an element of \(J\).

3.3-3 JordanD
‣ JordanD( cub1, cub2, cub3 )( operation )

Returns \(D_{\text{cub1}, \text{cub2}}(\text{cub3}) = \{\text{cub1}, \text{cub2}, \text{cub3}\} = U_{\text{cub1}, \text{cub3}}(\text{cub2})\), which is an element of \(J\).
