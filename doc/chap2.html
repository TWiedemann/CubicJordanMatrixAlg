2 Conic algebras and their base rings

Throughout this documentation, we use the term "conic algebra" to mean "(free) multiplicative conic alternative algebra". Internally, these algebras are represented in CubicJordanMatrixAlg by free nonassociative algebras, that is, by magma rings over free magmas. If a = b evaluates to true for two elements a, b of a conic algebra, this implies that a=b is indeed an identity (in a free conic algebra, and hence in all conic algebras). However, if a = b evaluates to false, this does not necessarily mean that a \ne b, but only that we have not proven that a=b.

See also Chapter 5 for functions to prove identities in conic algebras (and in structures built from conic algebras).

2.1 Constructing conic algebras and their elements

2.1-1 ConicAlgebra
‣ ConicAlgebra( comRingRank, conicRank, maxTrLength, nameRec )( operation )
‣ ConicAlgebra( comRingRank, conicRank, maxTrLength, comSym, conicSym )( operation )
‣ ConicAlgebra( comRingRank, conicRank, maxTrLength )( operation )
‣ ConicAlgebra( comRingRank, conicRank )( operation )
‣ ConicAlgebra( a )( operation )

The first variant creates a new (free) conic algebra object C on conicRank generators over a commutative ring with comRingRank generators. For all products d of length at most maxTrLength of generators of the conic algebra, the symbol tr(d) is initialised during the construction of C. This guarantees that an element of C in which no traces of products of higher length appear is always printed in the same way. The printing of elements containing traces of products of higher length, on the other hand, may depend on the order in which these traces have appeared in the current GAP session. (See [Wie26] for a slightly more detailed discussion of the parameter maxTrLength.)

The record nameRec may contain the following entries:

  • comSym: The symbol used for the generators in the commutative base ring, which are named comSym1, comSym2, .... Default: t.

  • conicSym: The symbol used for the generators in the conic algebra, which are named conicSym1, conicSym2, .... Default: a.

  • zeroSym: The symbol used for the zero element of the conic algebra. Default: 0_C.

  • oneSym: The symbol used for the one element of the conic algebra. Default: 1_C.

There are several variants of ConicAlgebra which use default values for the omitted arguments. The default value for maxTrLength is 4.

For an element a of a conic algebra, ConicAlgebra(a) is the (full) conic algebra containing a.

2.1-2 ConicAlgIndet
‣ ConicAlgIndet( C, p )( operation )

Returns the p-th indeterminate in C. We must have 1 <= p <= ConicRank(C).

2.1-3 AssignGeneratorVariables
‣ AssignGeneratorVariables( C )( method )

This function defines global GAP variables that store the indeterminates of C of and of its base ring. The names of the GAP variables coincide with the names of the indeterminates. Any previously defined GAP variables with these names will be overwritten.

gap> C := ConicAlgebra(4, 2, 3, "b", "t");;
gap> t1*b2;
Error, Variable: 't1' must have a value
not in any function at ...
gap> AssignGeneratorVariables(C);
gap> t1*b2;
(t1)*b2

This function also defines global variables dd := Liedd and g1 := ComRingGamIndet(1), g2 := ComRingGamIndet(2), g3 := ComRingGamIndet(3) that are independent of C.

2.2 Maps defined on conic algebras

2.2-1 ConicInv
‣ ConicInv( a )( operation )
‣ ConicConj( a )( operation )

Returns the conjugate of a. If a is a generator of the conic algebra in which it is contained, then its conjugate is printed as a'. ConicInv and ConicConj are different names for the same function.

2.2-2 ConicNorm
‣ ConicNorm( a )( operation )

Returns the norm of a. If a is a generator of the conic algebra in which it is contained, then its norm is printed as n(a).

2.2-3 ConicNormLin
‣ ConicNormLin( a, b )( operation )

Returns tr(a'b), which is known to be the same as n(a+b)-n(a)-n(b). Thus ConicNormLin is the linearisation of ConicNorm.

2.2-4 ConicTr
‣ ConicTr( a )( operation )

Returns the trace of a. If a is a generator of the conic algebra in which it is contained, then its trace is printed as tr(a). Several measures are taken to simplify (the display of) traces:

  • Multiplication signs in the argument of the trace are not printed: For a=a1*a2, the trace of a is printed as tr(a1a2)

  • By the relation tr((ab)c) = tr(a(bc)), we can omit brackets in products of length at most 3, so the result of ConicTr((a1*a2)*a3) is printed as tr(a1a2a3).

  • Using in addition the relations tr(a') = tr(a) and tr(ab) = tr(ba), the arguments of the trace are often permuted and/or replaced by their conjugates to ensure proper cancellation of terms. For example, both ConicTr(a1*ConicInv(a2)) and ConicTr(ConicInv(a1)*a2) evaluate to tr(a1a2'), and ConicTr(ConicInv(a1)*a2*a3) evaluates to tr(a1a3'a2') (which is correct because tr(a1'a2a3) = tr((a1'a2a3)') = tr(a3'a2'a1) = tr(a1a3'a2')).

2.3 Additional information stored in a conic algebra

2.3-1 ComRingOfConicAlg
‣ ComRingOfConicAlg( C )( operation )

Since GAP does not support function fields (or polynomial rings) over infinitely many indeterminates, it is not possible to return a commutative ring containing all symbols tr(d) for all monomials d in C of arbitrary length. Instead, this function returns the function field over the finitely many indeterminates which were initialised during the construction of C. In particular, for elements tr(d) where d is a product in C of sufficiently high length, the expression tr(d) in ComRingOfConicAlg(C) evaluates to false. Thus the user should not rely on this ring to be the full coeficient ring. However, it may be safely used to access Zero(ComRingOfConicAlg(C)) and One(ComRingOfConicAlg(C)).

2.3-2 ConicAlgMaxTrLength

Returns the parameter maxTrLength that was specified during the construction of C.

2.4 Base rings of conic algebras

2.4-1 ComRingIndet

2.4-2 ComRingGamIndet
‣ ComRingGamIndet( i )( operation )

Returns the i-th element of \Gamma = (\gamma_1, \gamma_2, \gamma_3). These are the (arbitrarily chosen, but fixed) constants that appear in the definition of cubic Jordan matrix algebras. They are printed as g1, g2, g3.
